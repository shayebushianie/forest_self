# 连续森林画布设置页设计

## 目标

设置页采用“连续森林画布 + 轻量分类导航 + 单一内容表面 + 弱边界控件”，消除深色分类块、双层外壳和多张白卡造成的隔离感，同时保留四个分类、全部设置字段、即时保存和无障碍行为。

## 结构

- `settingsPage` 提供整页森林渐变背景。
- `settingsGlassShell` 是页面内唯一连续内容表面，使用低饱和浅森林色和单一圆角轮廓。
- `settingsRail`、`settingsContentPanel` 和 `settingsListGroup` 不再绘制独立不透明底色或外框。
- 分类导航通过图标、文字、留白和轻量选中态区分；不使用整块深绿色栏。
- 内容分组通过标题、间距和细分隔线组织，不恢复独立白色卡片。

## 控件与交互

- 植物、计时模式、项目标签三类选择项保持整行可点击，点击文字区或空白区均打开尾部选择列表。
- 输入框、组合框和数值框默认使用浅森林填充与弱边界；hover 只轻微增强，focus 使用清晰焦点环。
- 布尔设置继续使用 `SproutToggle`，状态文字和复选框无障碍语义保持不变；不在外层设置行重复绘制边框。
- 数据动作保持整行按钮；危险恢复操作继续仅以文字色区分。
- 分类切换、键盘操作和高频设置操作即时完成，不新增动画。

## 无障碍与高对比

- 四个分类和全部控件保留键盘焦点、accessibleName 与 tooltip。
- 125% 字号下允许说明文字换行并通过滚动访问全部内容。
- 高对比模式只增强单一表面、分隔线、控件焦点和必要边界，不恢复深色分类块或多卡片结构。

## 验收

- 单独渲染时，分类栏、内容面板和设置分组不绘制不透明独立表面；外壳仍绘制连续内容表面。
- 三类选择行均能通过整行鼠标点击打开对应列表。
- 1366×768、1440×900、1920×1080 下四分类无裁剪、横向溢出或方形底色泄露。
- 125% 字号及高对比模式仍保持连续画布层级。
- Release 构建和全部 6 项 CTest 通过。
