# 异色发掘场景化设计

## 目标

在不改变抽取、扣币、重复返还和收藏数据的前提下，将“异色发掘”从通用双面板改为与“我的森林”一致的卡通自然场景。画面要有有机细节和空间层次，但不堆叠无意义装饰；文案直接说明操作与结果。

## 视觉结构

- 左侧以“林间发掘台”为视觉主角：低矮、柔软、不规则的林间空地由草缘包住土面，发掘坑直接嵌入地表。取消厚重棕色剖面平台和横向分层切片，只以自然起伏、少量裸土、石块、草簇、工具和异色裂隙形成层次。
- 土地轮廓保持左右不完全对称，草缘与裸土边界使用连续曲线；阴影贴近地面且较浅，避免悬浮岛、容器或通用图标感。工具应自然插入土边，不覆盖坑位和结果植物。
- 植物按实际不透明边界缩放并将最低像素锚定到统一地面点。场景按“后侧坑沿与接触阴影、植物、前侧土沿”的顺序绘制，用固定前景土沿遮住素材自带泥土底座，使树干、花茎和仙人掌基部进入土地；不对原素材执行颜色抠除。
- 场景下方只保留单次消耗、当前金币、重复返还三项信息，以及唯一主操作“开始发掘”。
- 发掘结果显示在场景中的独立浅色信息区，植物图像是焦点；无结果、新发现、重复发现分别使用直接状态文案。
- 右侧为四列图鉴网格。已发现项显示异色植物、名称和稀有度；未发现项使用统一剪影与“未发现”，不重复展示长说明。

## 约束与验证

- 不改变 `GachaManager`、金币结算、存储格式或成就触发。
- 使用 Qt Widgets、QPainter 和现有植物资源，不新增外部图片依赖。
- 场景应包含连续曲线路径和少量纹理细节，不能退化为单纯矩形/圆形拼接；石块不超过 3 处、草簇不超过 4 处，避免重新变得繁杂。
- 空状态的坑位、工具、裂隙和土地必须形成一个完整构图；获得异色后只替换坑位焦点，不改变土地轮廓或导致植物遮住主要细节。
- 全透明图片按空状态处理；不透明边界在设置结果时缓存，重绘过程不重复扫描图片像素。
- UI smoke 覆盖场景、图鉴网格、直接文案、发掘后结果和截图；视觉审查 1366×768、1440×900、1920×1080。
