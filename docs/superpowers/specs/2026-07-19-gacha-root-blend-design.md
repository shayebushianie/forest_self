# 异色植物根部独立融合设计

## 目标

异色植物不得依赖后绘制的土地遮挡根部。植物素材自带的宽泥土底座应在植物图层内部处理，最终只留下可辨识的根颈和少量根须，与连续裸土地表自然接触。

## 绘制与处理

- 保持原始植物图片和 `setDiscoveredPlant(const QPixmap&, const QColor&)` 接口不变。
- 设置结果时缓存不透明边界，并生成仅供发掘场景使用的融合副本；不修改资源文件，也不影响商城和图鉴图片。
- 融合副本从不透明边界高度的 74% 开始处理：横向保留区逐步收尖，纵向透明度平滑降低，去掉宽泥土底座形成的横向块面。
- 结果态绘制顺序为土地、贴地接触阴影、短根须、处理后的植物。土地和坑沿不得在植物之后绘制。
- 根须使用克制的暖棕色曲线，范围限制在根颈附近；结果态不显示深色坑洞，仅保留浅接触阴影。空状态继续显示坑位和裂隙。

## 验收

- 合成植物的中央根颈在地面接触区可见，横向测试底座基本消失。
- 橡树、松树、玫瑰、银杏、向日葵和仙人掌均无第二块宽泥土底座、无矩形土柱、无土地覆盖根部。
- 根部两侧裸土颜色连续，接触阴影不形成深色坑洞或独立平台。
- 三档分辨率结果态无裁切；完整 CTest 通过后才部署根目录程序。
