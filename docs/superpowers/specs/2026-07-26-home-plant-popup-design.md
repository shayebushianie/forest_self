# 主页植物选择 Popup 设计

## 目标

主页植物入口打开无边框选择层。点击外部空白或按 Escape 关闭且不修改当前植物；
只有点击已解锁植物卡片时才保存并刷新主页植物。

## 交互设计

- 使用 `Qt::Popup | Qt::FramelessWindowHint`，由 Qt 负责外部点击关闭。
- Popup 非模态，不调用 `exec()`；外部点击只关闭选择层，不触发主页底层操作。
- Popup 以主页植物入口为锚点，在主窗口可见区域内居中偏上显示。
- 同一时间最多存在一个 Popup；重复触发时聚焦并置顶已有 Popup。
- Escape 使用 Qt Popup 的默认关闭行为。
- 选择卡片后执行现有设置同步与主页植物刷新，再关闭 Popup。
- 关闭、外部点击或 Escape 均不触发持久化，也不更改当前植物。

## 边界

- 不修改植物解锁、商城、植物目录、偏好字段或数据格式。
- 不新增过渡动画；植物入口属于高频操作，应即时打开和关闭。
- 保留现有无边框森林卡片视觉和键盘可访问的植物按钮。

## 验证

- 点击主页植物入口后出现非模态、无边框 Popup。
- 点击主窗口空白区域后 Popup 关闭，设置页植物值保持不变。
- 按 Escape 后 Popup 关闭，设置页植物值保持不变。
- 点击另一张植物卡片后 Popup 关闭，设置页和主页植物同步更新。
- 完整 UI smoke 与六项 CTest 通过。
